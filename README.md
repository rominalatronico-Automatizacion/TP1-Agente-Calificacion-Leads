TP1 - Agente de Calificación de Leads

Descripción del proyecto
Desarrollo de un agente de Inteligencia Artificial para calificar leads de una academia de cursos de Inteligencia Artificial y Automatización.

Tecnologías utilizadas
- **n8n:** orquestación y automatización del flujo.
- **Google Gemini:** procesamiento del lenguaje natural y análisis de consultas.
- **Google Sheets:** consulta de la base de datos de leads.
- **Gmail:** envío automático de reportes de ejecución.

Funcionamiento
1. Recibe consultas mediante el chat.
2. Analiza la necesidad y el nivel de interés del potencial alumno.
3. Consulta la base de datos de Google Sheets cuando corresponde.
4. Genera una respuesta y registra la ejecución.
5. Envía un reporte por correo electrónico para supervisión.

Objetivo
Automatizar la atención inicial y la calificación de potenciales alumnos, manteniendo controles para evitar confirmar inscripciones o pagos sin validación.
